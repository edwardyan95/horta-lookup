How this works

The tool applies the saved dataset-specific conversion from Horta XYZ to CCF AP, DV, ML. It queries the Allen CCFv3 2017 annotation at 25 µm and includes MRN subdivisions 539, 548 and 555 under MRN 128.

613814 uses the verified affine conversion. Its public nonlinear file is incomplete. 609281 can use its complete original 25 µm affine and nonlinear transforms, or an explicitly selected affine-only comparison.

Membership uses the nearest annotation voxel. Distance is measured to the MRN voxel boundary; the 3D mesh is for orientation. A point within 100 µm is marked near the boundary for review, without implying a known error margin.
